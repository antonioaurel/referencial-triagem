Conectar

Esta página lê e grava a triagem direto no repositório privado antonioaurel/phd pela API do GitHub. Para isso ela precisa de um token fine-grained, criado por você e guardado só neste navegador. (No computador, aberta pelo serve.py em http://127.0.0.1:8765/triagem/, ela grava nos arquivos locais e não precisa de token.)

  1. Abra Fine-grained tokens.
  2. Resource owner: antonioaurel · Repository access: Only select repositories → phd.
  3. Repository permissions → Contents: Read and write.
  4. Toque em Conectar para triar no pé da página e cole o token (começa com github_pat_).

O token fica em localStorage deste aparelho (o mesmo da página Artigos × Bases publicada) e nunca aparece na URL nem no código. Para sair, use “desconectar” no pé da página.
